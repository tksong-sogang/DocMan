# DocMan PRD (MVP)

> 근거 문서: `docs/Plan.md` · 상태: 확정 (2026-09-26) · 변경: F017 자료 삭제 추가 (2026-09-26)

## 1. 제품 개요

문서(.pdf, .docx, .md, .txt)나 사진을 올리면 Gemini가 분석·요약하고, 원본과 분석 결과를 사용자의 Google Drive `DocMan` 폴더에 저장하는 1인용 웹앱(PWA)이다. 대시보드에서 목록·검색·주제 그래프로 저장된 자료를 다시 찾아본다.

- 플랫폼: PC 브라우저, 안드로이드 PWA (같은 코드)
- 저장소: Google Drive (서버 없음)
- MVP 제외: HWP, 여러 사용자, 자료 수정, 여러 자료 한꺼번에 삭제

## 2. 기능 명세

| ID | 기능명 | 설명 | 페이지 |
|---|---|---|---|
| F001 | Google 로그인 | Google 계정으로 로그인해 Drive 접근 토큰(`drive.file`)을 받는다. 토큰이 만료되면 다시 로그인을 요청한다. | P01 |
| F002 | 로그아웃 | 토큰을 폐기하고 로그인 페이지로 이동한다. | P05 |
| F003 | Gemini API 키 설정 | API 키를 입력·변경·삭제한다. 키는 브라우저 localStorage에만 저장한다. 키가 없으면 업로드 페이지에서 설정으로 안내한다. | P05 |

| F005 | 파일 업로드 | 드래그 앤 드롭이나 파일 선택으로 한 번에 파일 1개를 올린다. 확장자로 카테고리(일반 문서/사진)를 정한다. 지원하지 않는 형식(HWP 등)은 안내 메시지를 보여준다. | P03 |
| F006 | 카메라 촬영 | 폰에서 [카메라] 버튼으로 촬영한 사진을 사진 카테고리로 올린다. | P03 |
| F007 | 문서 분석 | 일반 문서에서 제목, 주제, 키워드(5개 이하), 핵심 내용(10줄 이하, 개조식)을 만든다. | P03 |
| F008 | 사진 분석 | 사진에서 글자를 추출해 제목, 주제, 키워드(3개 이하), 핵심 내용(4줄 이하)을 만든다. | P03 |
| F009 | 자료 저장 | 분석 결과를 확인한 뒤 [저장]을 누르면 ① 원본 저장 ② 자료별 MD 저장 ③ 누적 표 MD 맨 위에 행 추가 ④ `index.json` 건수·주제·항목 갱신을 차례로 한다. | P03 |
| F010 | 카테고리 현황 | [일반 문서], [사진] 박스에 주제 수와 건수를 보여준다. 값은 `index.json`의 누적 카운트를 그대로 읽는다. | P02 |
| F011 | 최근 자료 목록 | 카테고리별로 최신 자료를 한 줄에 '제목 · 주제 · 키워드'로 보여준다. 처음 10개, 스크롤하면 10개씩 더 보여준다. | P02 |
| F012 | 요약 박스 | 목록·검색 결과에서 항목을 누르면 팝업으로 제목과 '핵심 내용'을 보여준다. [원문 보기], [닫기] 버튼이 있다. | M01 |
| F013 | 원문 보기 | 요약 박스의 [원문 보기]를 누르면 Drive 원본 파일을 새 탭으로 연다. | M01 |
| F014 | 검색 | 주제나 키워드(부분 일치)로 찾은 결과를 [일반 문서], [사진]으로 나눠 10개씩 보여준다. 스크롤로 더 보고, [닫기]로 닫는다. | P02, M02 |
| F015 | 그래프 분석 | 주제를 노드로, 두 주제가 공유한 키워드 수를 연결선으로 그린다. 노드를 누르면 그 주제로 F014 검색을 실행한다. | P04 |
| F016 | PWA 설치 | 폰·PC에서 홈 화면(앱)으로 설치할 수 있다. | 전체 |
| F017 | 자료 삭제 | 요약 박스의 [삭제]를 누르고 확인하면 그 자료 1건을 지운다. ① `index.json`에서 항목을 빼고 건수·주제 건수를 1 줄인다(0이 된 주제는 없앤다) ② 누적 표 MD에서 그 행을 뺀다 ③ 원본과 자료별 MD를 Drive 휴지통으로 옮긴다(30일 안에 Drive에서 복구 가능). | M01 |

## 3. 메뉴 구조

```
[로그인 전]
└─ P01 로그인 ................ F001, F004

[로그인 후] 상단 메뉴: 대시보드 | 업로드 | 그래프 | 설정
├─ P02 대시보드 (홈) ......... F010, F011, F014
│   ├─ M01 요약 박스 ......... F012, F013, F017
│   └─ M02 검색 결과 박스 .... F014
│        └─ M01 요약 박스
├─ P03 업로드 ................ F005, F006, F007, F008, F009
├─ P04 그래프 분석 ........... F015, F014
│   └─ M02 검색 결과 박스 (노드 클릭)
│        └─ M01 요약 박스
└─ P05 설정 .................. F002, F003
```

- P = 페이지, M = 팝업(모달)
- F016(PWA 설치)은 특정 페이지가 아니라 앱 전체에 적용된다.

## 4. 페이지별 상세

### P01 로그인 (`/login`)
- 구성: 앱 이름 'DocMan', [Google로 로그인] 버튼
- 동작
  - 로그인 성공 → F004 초기화 실행(진행 중 표시) → P02로 이동
  - 로그인 실패·취소 → 오류 메시지를 보여주고 P01에 머문다
- 로그인하지 않은 상태로 다른 페이지에 들어오면 P01로 보낸다.
- 관련 기능: F001, F004

### P02 대시보드 (`/`)
- 구성
  - 검색창: 입력 후 Enter 또는 [검색] → M02 열림 (F014)
  - 1단계 박스 2개: [일반 문서] · [사진] — 주제 수, 건수 (F010)
  - 2단계 박스 2개: 카테고리별 최근 자료 목록, 한 줄에 '제목 · 주제 · 키워드', 10개씩 스크롤 로드 (F011)
- 동작
  - 목록 항목 클릭 → M01 열림 (F012)
  - 자료가 없으면 "등록된 자료가 없습니다"와 [업로드] 바로가기를 보여준다.
- 관련 기능: F010, F011, F012, F014

### P03 업로드 (`/upload`)
- 구성
  - 드롭 영역 + [파일 선택] 버튼 (F005)
  - [카메라] 버튼: 폰에서만 보인다 (F006)
  - 분석 결과 영역: 카테고리, 제목, 주제, 키워드, 핵심 내용 (F007, F008)
  - [저장], [취소] 버튼 (F009)
- 동작
  1. 파일 선택·촬영 → 카테고리 판별 → 분석 실행(진행 중 표시)
  2. 분석 결과 표시 → [저장] 누르면 F009 실행 → 완료 메시지 후 P02로 이동
  3. [취소] → 결과를 버리고 처음 상태로
- 예외
  - Gemini API 키 없음 → "설정에서 API 키를 입력하세요"와 P05 바로가기
  - 지원하지 않는 형식 → "지원하지 않는 형식입니다 (HWP는 PDF로 변환해 올려주세요)"
  - 분석·저장 실패 → 오류 메시지와 [다시 시도]
- 관련 기능: F005, F006, F007, F008, F009

### P04 그래프 분석 (`/graph`)
- 구성: 주제 연관 그래프 (확대·이동 가능)
- 동작: 노드(주제) 클릭 → 그 주제로 검색해 M02 열림
- 자료가 없으면 "그래프로 보여줄 주제가 없습니다"를 표시한다.
- 관련 기능: F015, F014

### P05 설정 (`/settings`)
- 구성
  - Gemini API 키 입력란(가림 표시), [저장], [삭제] (F003)
  - 로그인한 Google 계정 표시, [로그아웃] (F002)
- 관련 기능: F002, F003

### M01 요약 박스 (팝업)
- 호출 위치: P02 목록, M02 검색 결과 (P04에서 연 M02 포함)
- 구성: 제목, 카테고리, 생성 일자, 핵심 내용, [삭제], [원문 보기], [닫기]
- 동작
  - [원문 보기] → Drive 원본을 새 탭으로 (F013) · [닫기] → 팝업 닫힘
  - [삭제] → "'제목'을 삭제할까요?" 확인 → 삭제 중 표시 → 팝업이 닫히고 목록·건수·검색 결과·그래프에 바로 반영 (F017)
  - 삭제 실패 → 오류 메시지를 보여주고 팝업은 열린 채로 둔다
- 관련 기능: F012, F013, F017

### M02 검색 결과 박스 (팝업)
- 호출 위치: P02 검색창, P04 노드 클릭
- 구성: 검색어 표시, [일반 문서] 결과 박스, [사진] 결과 박스(각각 10개씩, 스크롤로 더 보기), [닫기]
- 동작: 항목 클릭 → M01 열림 · 결과가 없으면 "검색 결과가 없습니다"
- 관련 기능: F014, F012

## 5. 데이터 정의

### 5.1 Drive 폴더 구조

```
DocMan/
├─ index.json
├─ Documents/
│  ├─ originals/      # 원본 문서
│  ├─ summaries/      # 자료별 분석 MD
│  └─ Documents.md    # 누적 표 (최신 행이 맨 위)
└─ Photos/
   ├─ originals/
   ├─ summaries/
   └─ Photos.md
```

### 5.2 항목(Item) 필드

| 필드 | 설명 |
|---|---|
| id | 고유 ID |
| category | `document` 또는 `photo` |
| title | 제목 |
| topic | 주제 (1개) |
| keywords | 키워드 목록 (문서 5개, 사진 3개 이하) |
| summary | 핵심 내용 줄 목록 (문서 10줄, 사진 4줄 이하) |
| createdAt | 생성 일자 (ISO 8601) |
| originalFileId, originalLink | Drive 원본 파일 ID와 보기 링크 |
| summaryFileId | 자료별 MD 파일 ID |

### 5.3 index.json

- `counts`: 카테고리별 건수. 저장할 때마다 1씩 올리고, 삭제할 때 1씩 줄인다 (다시 집계하지 않는다).
- `topics`: 카테고리별 `{ 주제: 건수 }`. 키 개수가 주제 수다. 삭제로 건수가 0이 되면 키를 없앤다.
- `items`: 항목 목록, 최신이 앞.

### 5.4 MD 파일

- 자료별 MD (`summaries/<생성일시>_<제목>.md`): 제목, 주제, 키워드, 핵심 내용, 생성 일자, 원본 링크를 표로 정리한다.
- 누적 표 MD (`Documents.md`, `Photos.md`): 열 = 제목 | 주제 | 키워드 | 핵심 내용 | 생성 일자 | 원본 링크. 새 행을 헤더 바로 아래에 넣는다. 핵심 내용 셀의 줄바꿈은 `<br>`로 쓴다. 삭제할 때는 원본 링크가 같은 행을 찾아 뺀다(원본 링크는 자료마다 다르다).
